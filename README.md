# WSU WOWY 26-27

Lineup and player stats from practice play-by-play tags.

- `index.html` - the app (one file, no dependencies)
- `data.json` - the team's data, encrypted with the team passcode

Open the site and enter the passcode.

## Updating after a new session

1. Open the site, go to **Admin**, and choose the new Synergy CSV. Fix anything it flags, then **Add rows**.
2. In Admin, click **Download data.json**.
3. Here on GitHub: **Add file > Upload files**, drop in `data.json` (it replaces the old one), and **Commit changes**.
4. Give it a minute, then reload the site.
